A fast type checker and language server for Python, written in Rust

Usage: zuban.exe <COMMAND>

Commands:
  check   Checks a file or project for type errors
  mypy    Type checks files like you would do when calling `mypy`
  server  Starts an LSP server
  help    Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version

      --untyped-function-return-mode <UNTYPED_FUNCTION_RETURN_MODE>
