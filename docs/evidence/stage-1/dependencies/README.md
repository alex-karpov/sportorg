# Dependencies, licences and vulnerabilities (TASK-7 criterion 2)

What: Python and Rust dependencies of `pysport@b548c35`, their licences and known
vulnerabilities, from the lock files at the pin and the network cache. Generated by
`scripts/archaeology/dependencies.py`; every number below comes from it.

Files (`.json` is the machine output, `.md` the table):
- `summary`: counts, input digests (per-file SHA-256 of the cache), top lists.
- `direct-dependencies`: requirement strings of `pyproject.toml` with marker, line and the
  versions `uv.lock` resolves them to.
- `python-packages`: every registry package of `uv.lock` (one row per version) with class,
  groups, Python 3.8 flag, licence, verdict, vulnerability count.
- `vulnerabilities-python`: own OSV records per package version.
- `rust-packages`: `Cargo.lock` packages, crates.io licence, OSV records.
- `crosscheck`: own OSV against `uv audit` and against osv-scanner, per record.

Definitions:
- Class `runtime`: reachable from `[project].dependencies` in `uv.lock`, environment markers
  ignored (the superset), as in `scripts/check_licenses.py`. Class `extra`: reachable only from
  `[project.optional-dependencies]` (`gui`, `win`). Class `dev`: every other package (dependency
  groups, anything unreachable). `groups` lists the groups that reach a package. The walk is per
  (name, version).
- Python 3.8 only: no path from any group to the package avoids an edge whose marker confines it
  to Python 3.8 (`python_full_version < '3.9'`, `== '3.8.*'`); a marker with `or` is not counted
  as confined.
- Licence: PyPI `license_expression`, else `License ::` classifiers, else the free-text
  `license` field (first line), else not declared; names and allowlist of
  `scripts/check_licenses.py` (target GPL-3.0-or-later). Verdict `ok` = allowlisted; `problem` =
  denied there; `unknown` = neither. Crates: the crates.io `license` string, `/` read as `OR`.
- Vulnerability: an OSV record returned by `POST /v1/query` for the exact package version. Fixed
  versions are the `fixed` events of the `affected[]` entries of that package. Labels are the
  record's `database_specific.severity`; CVSS strings are copied, not scored.
- Cross-check: records match when their ids and aliases share a value. `both` is counted once
  per own record; `only other` counts the other tool's records with no own match.

Limits:
- OSV is queried per exact version; whether legacy uses the vulnerable code path is not
  assessed. The data are the responses cached on the fetch date, not today's.
- `Cargo.lock` has no runtime/dev split; crates are not classed. Local crates have no registry
  licence or OSV lookup.
- Packages without a cache file are listed in `summary.json` (`missing_cache_files`).
- `uv audit` and osv-scanner results are cached runs on temporary copies of the lock files;
  paths are reduced to the file name.
- Author and maintainer fields of PyPI/crates metadata are not read (personal data).
