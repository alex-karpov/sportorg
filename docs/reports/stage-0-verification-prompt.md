Ты — независимый проверяющий. Репозиторий в текущем каталоге — проект `sportorg_ng` (модернизация программы хронометража SportOrg). Legacy лежит внутри, в двух git-игнорируемых клонах закреплённых коммитов: `.legacy/pysport` (программа) и `.legacy/templates` (русские шаблоны отчётов). Их можно читать, но нельзя изменять и нельзя исполнять. Если их нет, получи их командой `uv run python -m scripts.legacy fetch`. Предыдущая сессия утверждает, что выполнила «этап 0 — минимальное окружение разработки» и исправила находки первой проверки. Проверь это, доверяя только тому, что сам запустишь и увидишь. Не читай `docs/reports/` и `docs/evidence/` до конца проверки; сначала собери собственные факты, потом сравни. Эксперименты, которые меняют файлы, делай на копиях во временном каталоге или откатывай сразу.

1. `AGENTS.md` — единственный источник инструкций; `CLAUDE.md` начинается с `@AGENTS.md` и добавляет только специфичное для Claude Code. Перечисли правила, которые повторяются в обоих файлах, если такие есть.
2. `uv sync`, затем `uv run python scripts/check.py --keep-going`: полный вывод, итог по шагам; в скрипте есть ruff (формат и линт), basedpyright, import-linter, pytest.
3. Канарейки (внеси, прогони `check.py --keep-going`, откати): (а) `import os` с использованием в `src/sportorg_ng/core/` → import-linter; (б) функция без аннотаций в `src/` → ruff и/или basedpyright; (в) `x: int = "s"  # type: ignore` → ошибка про игнор без кода; (г) сломанный тест.
4. Pre-commit: сравни `.pre-commit-config.yaml` с шагами `check.py`. Выполни `uvx --python 3.14 pre-commit@4.7.0 run --all-files` и `uvx --python 3.14 pre-commit@4.7.0 run --all-files --hook-stage pre-push`; приложи выводы.
