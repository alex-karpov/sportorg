Every risk names the stage whose prototype or test checks it, and the evidence that counts.
Sources: `[код]` legacy code, `[история]` legacy git/issues, `[мейнтейнер: дата]`, `[допущение]`.
Stage numbers refer to `docs/brief.md`. Update this file when a stage adds evidence.
