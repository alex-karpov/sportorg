# Проверка находок F3, F4, F6 в GUI legacy

Находки описаны в `docs/evidence/stage-2/oracle/findings.agent.md`. Для каждой есть синтетический файл гонки без персональных данных: «Synthetic Runner NNN», чип 0, без даты рождения. Файлы и выводы оракула записаны скриптами: `uv run python -m scripts.oracle_evidence run --out docs/evidence/stage-2/oracle`.

| Находка | Файл | Вывод оракула |
|---|---|---|
| F3 | `docs/evidence/stage-2/oracle/inputs/f3_rogaine_tie.json` | `synthetic/f3_rogaine_tie/results.json` |
| F4 | `docs/evidence/stage-2/oracle/inputs/f4_slow_leader.json` | `synthetic/f4_slow_leader/results.json` |
| F6 | `docs/evidence/stage-2/oracle/inputs/f6_two_races.json` | `synthetic/f6_two_races/results.json` |

## Перед проверкой

- **Версия.** Оракул считает версией `v1.8.0b2`, коммит `pysport@b548c35` `[код: pysport@b548c35 sportorg/config.py:10]`. В другой версии SportOrg результат может быть другим, поэтому запишите, какой версией проверяли.
- **Как запустить закреплённую версию** в отдельном checkout на Windows:
  ```
  uv run python -m scripts.legacy fetch
  uv run python -m scripts.legacy_clone --name pysport
  uv run python -m scripts.legacy_env sync --python 3.8
  .legacy-run\pysport\.venv\Scripts\python.exe .legacy-run\pysport\SportOrg.pyw
  ```
  `[допущение: последняя команда на Windows не проверялась]`
- **Скопируйте файлы** во временную папку и открывайте копии. Если сохранить файл, legacy перезапишет его, а это evidence из репозитория.
- **Где смотреть.** Вкладка «Результаты», колонки «Номер», «Место», «Результат», «Отставание».
  - В режиме по очкам «Результат» показывает `N очк. ЧЧ:ММ:СС` `[код: pysport@b548c35 sportorg/models/memory.py:702-719]`.
  - «Отставание» показывается как время, пустое — если отставания нет `[код: pysport@b548c35 sportorg/gui/tabs/memory_model.py:486-494]`.
  - Строки могут идти не по месту, поэтому сверяйте по номеру.

Ожидаемые значения в таблицах ниже взяты из вывода оракула. Исключение — колонка «сразу после открытия» для F6, о ней ниже.

## F3. Меньше очков при равном времени — то же место

Файл `f3_rogaine_tie.json`, рогейн: лимит 60:00, очки — код КП // 10.

Откройте файл: «Файл → Открыть». При открытии legacy пересчитывает результаты сам.

| Номер | Место | Результат | Отставание |
|---|---|---|---|
| 1 | 1 | 10 очк. 00:40:00 | — |
| 2 | 2 | 7 очк. 00:45:00 | 00:05:00 |
| 3 | 2 | 5 очк. 00:45:00 | 00:05:00 |

F3 подтверждается, если у номера 3 (5 очков) место 2 — такое же, как у номера 2 (7 очков). Лидер самый быстрый, поэтому F4 здесь не возникает.

## F4. Отставание от более медленного лидера переходит через полночь

Файл `f4_slow_leader.json`, тот же рогейн, времена без совпадений.

| Номер | Место | Результат | Отставание |
|---|---|---|---|
| 1 | 1 | 10 очк. 00:55:00 | — |
| 2 | 2 | 7 очк. 00:50:00 | 23:55:00 |
| 3 | 3 | 5 очк. 00:58:00 | 00:03:00 |

F4 подтверждается, если у номера 2 отставание 23:55:00: он на 5:00 быстрее лидера, и −5:00 становится 23:55:00.

## F6. Нетекущая гонка многогоночного файла

Файл `f6_two_races.json`: две гонки, текущая — первая, многодневки нет.

- «Race 1 individual» — личная гонка, как в `individual.json`.
- «Race 2 rogaine» — рогейн. Порядок по очкам в нём обратен порядку по времени.

Шаги:

1. «Файл → Открыть». Откроется первая гонка.
2. «Файл → Настройки» (Ctrl+Alt+S), вкладка «Многодневные соревнования». Выберите в списке «Race 2 rogaine» — гонка переключается сразу при выборе — и закройте окно.
3. На вкладке «Результаты» запишите место, результат и отставание. Это колонка «сразу после открытия».
4. Выберите «Результаты → Перепроверить отметку» (Ctrl+R). Это пересчёт текущей гонки в её собственном контексте `[код: pysport@b548c35 sportorg/gui/menu/menu.py:401-405, sportorg/gui/menu/actions.py:638-642]`. Запишите значения ещё раз.

| Номер | Сразу после открытия (ожидание) | После «Перепроверить отметку» (оракул) |
|---|---|---|
| 1 | место 3, 0 очк. 00:50:00, отставание 00:10:00 | место 1, 10 очк. 00:50:00, — |
| 2 | место 2, 0 очк. 00:45:00, отставание 00:05:00 | место 2, 7 очк. 00:45:00, 23:55:00 |
| 3 | место 1, 0 очк. 00:40:00, — | место 3, 5 очк. 00:40:00, 23:50:00 |

**Откуда ожидание «сразу после открытия».** Оно выведено из кода:
- при открытии legacy пересчитывает вторую гонку, пока текущая — первая, и проверка отметок идёт по текущей гонке, поэтому очки второй гонки не считаются `[код: pysport@b548c35 sportorg/modules/backup/json.py:42-44, sportorg/models/result/result_tools.py:106, sportorg/models/result/result_checker.py:98-99]`;
- переключение гонки вне многодневки ничего не пересчитывает `[код: pysport@b548c35 sportorg/gui/dialogs/settings.py:317-329, sportorg/gui/main_window.py:678-687]`.

Разовый прогон агента 2026-11-01 показал именно эти значения, но в evidence он не сохранён.

**Как понять результат проверки:**
- F6 подтверждается, если до перепроверки значения как в средней колонке, а после — как в правой.
- Если уже до перепроверки значения как в правой колонке, GUI пересчитывает гонку при переключении, и F6 в GUI не проявляется.

Во второй гонке после перепроверки виден и F4: номера 2 и 3 быстрее лидера.

## Что прислать

Для каждого файла: совпало или нет, и версия SportOrg. Если не совпало — значения или снимок экрана. Снимок безопасен: в файлах нет персональных данных.
